# Line S.A.

Celulares y consolas, venta retail y atención mayorista.

Mini shop con catálogo en guaraníes, carrito persistente y consulta por WhatsApp. El checkout permite simular tarjeta, transferencia y cuotas Line; no procesa cobros ni confirma compras.

## Publicación

GitHub Pages publica desde `main`, carpeta raíz. `.nojekyll` permite servir directamente los archivos HTML, CSS, JavaScript y `assets/`.

Los cambios en `main` actualizan la web. Este repositorio contiene exclusivamente los archivos públicos del sitio, sin precios internos del proveedor ni credenciales.
